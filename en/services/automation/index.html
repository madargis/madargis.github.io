GIS Workflow Automation

A custom Python, ArcPy or PyQGIS tool that automates a GIS task you repeat, delivered with tests and a user guide.

From USD 300Delivered by Madar

Request this service

The problem

A task done by hand every week: batch map production, checking, conversion, area reports. Time is lost and the same errors return.

Who it is for

GIS teams at consultants and contractors that lack a programmer, and small consultancies repeating the same task every week.

A starting price. The final price is written in a one-page offer.

What you receive

  • A tool that runs inside ArcGIS Pro (a .pyt file), in QGIS or from the command line.
  • A two-page user guide and test data.
  • A test file proving the output matches the agreed example.
  • The source code, where the offer says so.
  • Bug fixing for a period written in the offer, then an optional maintenance contract.

What you supply

  • A step-by-step description of the task.
  • Sample inputs.
  • A correct output example produced by hand.
  • Software version and operating system.
  • Who will run the tool.

How the work goes

  1. You tell us what the task is, how often it repeats and how long it takes by hand.
  2. A 30-minute session where you show the task on your screen.
  3. We write a one-page specification: inputs, outputs, edge cases and the acceptance criterion, which is that the output matches the example.
  4. We send a fixed-price offer with a maintenance clause.
  5. We build a first version on the sample data and send it within the first week.
  6. You try the tool on your data in your environment, and the notes go into a single list.
  7. One revision round is included in the price. Anything beyond it needs a written change note.
  8. We write the tests and the guide, and block overwriting of source files.
  9. We deliver the tool, the guide and the test data, with a run-through session with the user. The acceptance period is 7 days.

Accuracy and limits statement

The tool is tested on the stated version and operating system and on the sample data. A change of software version or data structure may require changes. The tool automates the steps; it does not validate input data beyond the checks listed in the guide.

Out of scope

  • Software licences
  • ArcGIS Enterprise and server administration
  • Integration with enterprise systems
  • Open-ended support without a contract
