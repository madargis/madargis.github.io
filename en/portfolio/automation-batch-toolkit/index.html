A 26-layer folder processed with five Madar Automation Toolkit commands

We prepared 26 open layers in three formats and five coordinate systems and ran them through reproject, clip, convert, merge and area report. The five steps took 15.7 seconds on this machine.

A demo built from open data, not a client project.

Demo date2026-11-20

Related serviceGIS Workflow Automation

The problem

Offices receive folders of dozens of layers in mixed formats and coordinate systems. Handling them one by one by hand is slow and error-prone.

The data

OpenStreetMap features (amenities, shops, roads, buildings, land use) in a 1.2 × 1.2 km box in east-central Riyadh (around Al Malaz), downloaded through the Overpass API on 2026-11-20 and split into 26 layers. Licence: ODbL, © OpenStreetMap contributors.

The method

  1. Split the extract into 26 layers in SHP, GPKG and GeoJSON, in EPSG 4326, 32638, 3857, 20438 and 9358, with one Shapefile missing its projection file as happens in real folders.
  2. reproject to KSA-GRF17 / UTM 38N (EPSG:9358).
  3. clip to an 450 m radius circle in the centre of the box.
  4. convert to GeoPackage, then merge into one file, then area for an area and perimeter report.
  5. Run each command unchanged from the command line and time it end to end.

The result

Times: reproject 3.3 s, clip 3.5 s, convert 3.4 s, merge 2.9 s, area 2.6 s; total 15.7 s, of which about 2.5 s per command is Python start-up and imports. reproject: 25 done and 1 failed (the layer with no coordinate system). clip: 21 done and 4 skipped as outside the boundary. Merge: 495 features from 21 files. Area report: 36.88 ha of polygons. Machine: Windows 10, 8 logical CPUs, Python 3.11.1.

Limits

Demonstration on open data, not a client project. The layers are small (largest 425 features), so the times are dominated by start-up and do not represent files with millions of features. Each command was timed once on one machine. reproject ends with an error code when one file fails, and the layer without a coordinate system needs its system set by hand. Shapefile field names are cut to 10 characters. The area total adds overlapping layers (buildings and land use), so it is not a land area; it was measured in EPSG:32638, which area picked by itself. The merge mixes points, lines and polygons in one layer. Failures: reproject: FAIL bus_stops.shp: no CRS defined | 1 of 26 files failed.
