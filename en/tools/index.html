Tools

Two command-line tools written in Python. They run on your files, on your machine.

Madar Quality Checker

A pre-delivery check with a report in Arabic and English

Checks a parcel or survey layer before it is handed over, and writes a report in Arabic and English.

The report folder receives issues.csv, one line per problem, and report.html, a summary in both languages.

From USD 100 per organisation

Request the tool

Request the tool through the request form by choosing “a ready-made tool”.

8

CheckWhat it needs
Coordinate reference system--epsg or --profile to compare against
Empty geometryalways runs
Invalid geometryalways runs
Duplicate geometryalways runs
Overlapping polygonsalways runs
Missing required attribute--required
Duplicate identifier--id-field
Recorded area differs from geometry--area-field

Example run

python quality_checker.py --input parcels.gpkg --report out --profile ksa-grf17 --id-field parcel_id --required owner land_use --area-field area_m2

What you should know

  • Row numbers start at 0 and follow the order of features in the file.
  • Layers in geographic coordinates are measured in the UTM zone of the layer centre.
  • Invalid polygons are reported but left out of the overlap check.
  • Only the first layer of a multi-layer GeoPackage is read.
  • Gaps between neighbouring parcels are not checked yet.
  • Issue details are written in English. Check names are in both languages.
  • The report checks data consistency only. It is not an official survey deliverable.

Testing

Tested with Python 3.11, geopandas 1.2, shapely 2.2 and pyogrio 0.13 on Windows.

Madar Automation Toolkit

Six commands that process whole folders

Six batch commands for everyday GIS work, run from the command line on a folder of files.

reproject, clip and convert read a folder and write to another folder. merge writes one file, area writes a CSV table and ndvi writes a GeoTIFF.

From USD 49 per individual

Request the tool

Request the tool through the request form by choosing “a ready-made tool”.

6
The six commands
CommandWhat it does
reprojectReprojects every vector file in a folder
clipClips every file to a boundary polygon
convertConverts between SHP, GPKG and GeoJSON
mergeMerges all files into one and adds a src_file column
areaArea and perimeter report with a valid flag per feature
ndviNDVI raster from red and near-infrared bands

Example run

python gis_toolkit.py reproject --input data --output out --epsg 32638

What you should know

  • A source file is never overwritten. If the output would replace an input, the command stops and names the files.
  • One unreadable file does not stop a batch: it is printed as FAIL, the rest are processed, and the command ends with an error code.
  • Layers without a coordinate system are rejected by reproject, clip, merge and area.
  • area measures in the UTM zone of the layer centre unless --epsg is given. For a layer wider than 6 degrees it prints a warning, because areas far from the centre can be off by about 2%.
  • ndvi reads both bands fully into memory. One Sentinel-2 tile needs about 2 GB.
  • Only the first layer of a multi-layer GeoPackage is read.

Testing

Tested with Python 3.11, geopandas 1.2, rasterio 1.4 and pyogrio 0.13 on Windows.
