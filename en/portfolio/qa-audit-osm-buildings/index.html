Quality check of OpenStreetMap buildings, Jarir District, Riyadh

We checked 2,285 OpenStreetMap building footprints in Jarir District (2.58 km²) with Madar Quality Checker. It found 8 overlaps and 17 footprints with no street name, and no invalid or duplicate geometry.

A demo built from open data, not a client project.

Demo date2026-11-20

Related serviceSpatial Data QA/QC and Accuracy Checks

The problem

A building layer delivered against a specification is rejected if it holds invalid geometry, duplicates, overlaps or empty attributes. The task is to count and locate these issues before delivery.

The data

OpenStreetMap buildings inside the Jarir District boundary (relation 13254462), downloaded through the Overpass API on 2026-11-20. Licence: ODbL, © OpenStreetMap contributors. Community data drawn by volunteers.

The method

  1. Download the buildings and the district boundary in one Overpass request and cache it.
  2. Assemble polygons with the GDAL OSM driver and keep the buildings inside the district boundary: 2,285 footprints.
  3. Run Madar Quality Checker: coordinate system EPSG:4326, empty, invalid and duplicate geometry, overlaps above 0.01 m², unique identifier, and completeness of the street name field.
  4. Join issues.csv to the footprints and map each issue by type.

The result

25 issues in 2,285 footprints. Geometry: 0 invalid, 0 duplicate, 0 empty, and 8 overlaps between 0.02 and 2.39 m². Repeated identifiers: 0. Coordinate system: 0 issues. Street name is missing on 17 footprints (0.7%). Outside the tool's checks: 0 footprints carry a number of levels, 133 have the generic type yes, and 0 building ways are not closed.

Limits

Demonstration on open data, not a client project. OpenStreetMap is community data, so the case shows the checking method and does not judge the ground truth. Desk check of data consistency as downloaded. No check points, so no statement on positional accuracy or on buildings that are not mapped. Gaps between polygons and value domains are not checked. Not an official survey deliverable.
